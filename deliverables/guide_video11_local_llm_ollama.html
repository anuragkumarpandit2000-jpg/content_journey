1. Why Run Models Locally?

Cloud LLM APIs (OpenAI, Anthropic) bill you per token, throttle high concurrency, and transmit sensitive client IP over third-party servers. With Ollama + GGUF, you get unmetered, zero-cost inference running completely offline on your workstation GPU or unified memory.

3. 3-Minute Setup Script (Windows / Mac / Linux)

# 1. Install Ollama
curl -fsSL https://ollama.com/install.sh | sh
# On Windows: Download installer from https://ollama.com/download

# 2. Pull & Run DeepSeek-R1 Distill or LLaMA 3.3
ollama run deepseek-r1:8b
# For coding tasks:
ollama run qwen2.5-coder:14b

# 3. Launch Dockerized Open WebUI (ChatGPT clone locally)
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data --name open-webui --restart always \
  ghcr.io/open-webui/open-webui:main

4. Python Integration via OpenAI-Compatible API

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama" # Required by client, ignored by Ollama
)

response = client.chat.completions.create(
    model="deepseek-r1:8b",
    messages=[{"role": "user", "content": "Write an async web crawler in Python."}]
)
print(response.choices[0].message.content)
