1. Overview & Architecture

Meta's official WhatsApp Business Cloud API requires cumbersome business verification, template approvals, and expensive per-message conversation charges. Using an open-source WhatsApp Web socket bridge (Baileys/WPPConnect), you can connect your existing phone number directly to a Python FastAPI backend driven by an LLM reasoning agent.

2. Core Python Handler (server.py)

from fastapi import FastAPI, Request
import google.genai as genai
import httpx

app = FastAPI()
client = genai.Client()

SYSTEM_PROMPT = """You are an autonomous business assistant for @parker.render.
Reply in friendly, concise Hindi/English. If the user asks for pricing, explain that packages start at ₹15,000.
If they want a portfolio, share https://parker-render.netlify.app."""

@app.post("/webhook")
async def handle_whatsapp_message(req: Request):
    data = await req.json()
    from_number = data.get("from")
    text = data.get("text", "")
    
    # Generate intelligent reply via Gemini
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=f"{SYSTEM_PROMPT}\nUser says: {text}"
    )
    reply_text = response.text.strip()
    
    # Send message back via socket bridge
    async with httpx.AsyncClient() as http:
        await http.post("http://localhost:3000/send-message", json={
            "phone": from_number,
            "message": reply_text
        })
    return {"status": "ok"}

3. Essential Anti-Ban Rules

  • Human Typing Delays: Never reply in 0.1s. Add random delay of 3–7 seconds before dispatching.
  • Warm-up Strategy: Start with 10–20 chats daily on a new number before scaling to hundreds.
  • Stateful Memory: Maintain conversation context per phone number in SQLite or Redis.
