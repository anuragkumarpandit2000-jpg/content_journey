1. Kill Background Battery Vampires & Telemetry

Out of the box, modern smartphones run hundreds of hidden analytics threads transmitting location pings and app usage metrics. Here is how to disable them:

  • Turn Off Google Usage & Diagnostics:
    Settings → Google → (Three dots top right) → Usage & Diagnostics → Toggle OFF.
    Impact: Prevents continuous CPU wake-locks when the screen is turned off.
  • Disable Nearby Device Scanning & Wi-Fi Throttling:
    Settings → Connected devices → Connection preferences → Nearby Share / Quick Share → Device visibility OFF.
    Settings → Location → Location Services → Wi-Fi scanning & Bluetooth scanning → Both OFF.
    Impact: Stops radio hardware from continuously broadcasting in the background.
  • Disable RAM Plus / Virtual RAM:
    Settings → Device Care → Memory → RAM Plus (Virtual RAM) → Set to OFF.
    Why: Virtual RAM uses slow NAND flash storage as swap memory. When your phone swaps RAM to disk, it causes lag, micro-stutters, and burns battery. Turning it off keeps all apps on fast physical LPDDR5 RAM.

2. Developer Options Secret Tuning (2x Snappier UI)

To unlock hidden performance configurations built into the Android core:

  1. Go to Settings → About Phone → Software Information.
  2. Tap Build Number rapidly 7 times until it says "You are now a developer!"
  3. Go back to Settings → Developer Options and configure:
    • Window animation scale: Set to 0.5x
    • Transition animation scale: Set to 0.5x
    • Animator duration scale: Set to 0.5x
    • Wi-Fi scan throttling: Keep ON (saves battery).
    • Mobile data always active: Turn OFF (stops dual radio drain while on Wi-Fi).

3. Cybersecurity & Anti-Adware Privacy Lockdown

Stop ad trackers, in-app malicious redirects, and carrier DNS spying with a single encrypted DNS profile:

🛡️ 1-Minute System-Wide Ad & Tracker Blocker (No Apps Needed):
  1. Go to Settings → Network & Internet → Private DNS.
  2. Select Private DNS provider hostname.
  3. Enter: dns.adguard.com or p2.freedns.controld.com
  4. Tap Save.

Result: Instantly blocks 98% of in-app banner ads, popups, and tracker SDKs across Chrome, games, and third-party apps without draining extra battery.

4. The Pro Deep-Clean: ADB Bloatware Removal (CLI)

Modern phones come pre-loaded with useless carrier and OEM bloatware (Facebook App Installer, Glance lockscreen, pre-installed games). You can remove them cleanly using an Android Debug Bridge (ADB) terminal from your PC:

# 1. Enable USB Debugging in Developer Options
# 2. Connect phone to PC and run in PowerShell:
adb devices

# 3. Uninstall Facebook background service and bloatware:
adb shell pm uninstall -k --user 0 com.facebook.katana
adb shell pm uninstall -k --user 0 com.facebook.system
adb shell pm uninstall -k --user 0 com.facebook.appmanager

# 4. Uninstall lockscreen ad providers (e.g. Glance):
adb shell pm uninstall -k --user 0 com.glance.internet
